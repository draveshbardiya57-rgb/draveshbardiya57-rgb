## 🚀 Featured Projects

### 🔹 Sketch2Face-Hybrid
> **Explainable Sketch-to-Photo Face Recognition System**  
> Built an end-to-end pipeline using **Pix2Pix GANs** for facial image synthesis, combined with **ArcFace** and **YOLOv8** for face matching and identification. Served via a **FastAPI** backend and **React** interactive dashboard.
* **Tech:** Python, PyTorch, OpenCV, FastAPI, React, MongoDB

### 🔹 Agentic RAG & Self-Healing Pipelines
> **Autonomous Search & Retrieval System**  
> An advanced RAG framework built using **LangGraph** that detects retrieval errors, re-evaluates search queries dynamically, and self-corrects context gaps before generating final answers.
* **Tech:** Python, LangGraph, Vector Databases, OpenAI/Ollama, FastApi
